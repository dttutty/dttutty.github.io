Smart Search for ChatGPT

Privacy Policy

Effective date: August 27, 2026

Smart Search for ChatGPT is an independent Chrome extension that improves navigation and natural-language search within ChatGPT. It is not affiliated with, endorsed by, or sponsored by OpenAI.

Data the extension processes

The extension processes the minimum data needed for its user-facing features:

  • ChatGPT conversation identifiers, titles, creation dates, and last-update timestamps obtained from ChatGPT conversation-list responses in the user's current signed-in ChatGPT session.
  • Search topics entered by the user in the Smart Search dialog and the generated search prompt.
  • Search-result table content already rendered by ChatGPT, only to turn creation-date cells into links to the corresponding original conversations.
  • The URL of the dedicated better search ChatGPT project and a temporarily pending search prompt in Chrome local extension storage.

The extension does not read or store ChatGPT authentication credentials, cookies, passwords, payment information, or the full message bodies of the user's conversation history.

How the data is used

The data is used only to:

  • Display conversation timestamps beside ChatGPT sidebar titles.
  • Generate a natural-language history-search prompt from the user's topic and optional time range.
  • Open a new search chat inside the better search ChatGPT project.
  • Link creation dates in search results to the matching original conversations.

When the user clicks Search, the generated prompt is entered into and sent through ChatGPT using the user's current ChatGPT session. OpenAI's processing of that prompt and the resulting ChatGPT response is governed by OpenAI's own terms and privacy policies.

Storage and retention

All extension-managed data remains in the user's browser:

  • Conversation metadata is kept only in page memory and is discarded when the ChatGPT tab is closed or reloaded.
  • A pending search prompt is removed after it is sent or expires after approximately two minutes.
  • The better search project URL remains in Chrome local extension storage until the user clears the extension's data or uninstalls the extension.

Data sharing and sale

The developer does not operate a server for this extension and does not receive, collect, sell, rent, or share user data. The extension contains no advertising, analytics, tracking pixels, or third-party SDKs.

The extension communicates only with ChatGPT as part of the user-requested search workflow. No user data is transmitted to the developer.

Chrome permissions

  • Storage: remembers the dedicated ChatGPT project URL and temporarily stores a pending search prompt while navigating to that project.
  • Access to chatgpt.com and chat.openai.com: injects the Smart Search interface, observes ChatGPT conversation-list metadata, displays timestamps, and links search results.

User control

Users can stop all processing by disabling or uninstalling the extension. Uninstalling the extension removes its Chrome local storage. Users can also clear extension data through Chrome settings.

Limited Use

Smart Search for ChatGPT's use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide the extension's disclosed single purpose and is not used for advertising, creditworthiness, or any unrelated purpose.

Changes to this policy

If the extension's data practices change, this policy and the Chrome Web Store disclosures will be updated before the changed practices take effect.
