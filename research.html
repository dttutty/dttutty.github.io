Research

My research focuses on Machine Learning Systems and Graph Neural Networks, with an emphasis on distributed training, communication, memory systems, and performance optimization.

Work in Progress

A Scalable Temporal Graph Neural Network Training Framework

Private GitHub repository

  • Identified an opportunity to hide dynamic-feature transfer latency while NCCL bandwidth is idle during the forward pass.

  • Designed a Planner–Syncer system that prepares data placement and asynchronously multicasts features for the next batch in parallel with the current forward pass.

  • Developed a hybrid synchronization strategy that uses P2P transport for high-dimensional features and shared memory for low-dimensional features.

  • Key technologies: PyTorch Distributed, caching, DGL, NCCL, Gloo, shared memory, multiprocessing, multithreading, and zero-copy communication.
